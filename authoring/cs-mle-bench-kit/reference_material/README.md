# Learning reference material

Drop the material you actually used to learn the topic here. Examples:

- lecture notes
- PDFs / papers
- README files
- source code snapshots
- blog exports
- docs
- your own notes

Then mention the relevant files in `../INPUT.md`.

The assessment generator is required to read these materials before designing the task. The point is to test the boundary of what you studied rather than silently requiring unrelated specialized knowledge.
